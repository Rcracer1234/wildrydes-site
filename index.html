What’s This Project?

This cloud-based web app is my attempt to build a full-stack application using AWS services. While powerful, working with the cloud isn't easy—it takes serious planning. I’m integrating tools like IAM, Amplify, Cognito, Lambda, API Gateway, DynamoDB, and GitHub to ensure a secure, scalable architecture. Cloud computing helps offload backend burdens and lets developers focus on functionality.

Version Control

All code is hosted on GitHub to maintain collaborative versioning and CI/CD practices.

Secure Access

IAM roles ensure only authorized users access specific parts of the system.

Frontend Hosting

AWS Amplify hosts and deploys the frontend with continuous updates from GitHub.

User Management

Amazon Cognito handles sign-up, sign-in, and token-based authentication securely.

Why It’s Difficult

Cloud development isn’t just writing code—it’s configuring services, ensuring scalability, security, and dealing with complex integrations. Serverless functions via AWS Lambda need precise triggers, and Amazon API Gateway must expose them with proper methods. Data storage with DynamoDB involves designing for fast, scalable access patterns. It’s challenging, but each service plays a key role in building a robust, real-world cloud-native app.
